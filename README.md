Projects

🔎 TryHackMe Benign – SOC Investigation

Tools: Splunk, Windows Event Logs
Focus: Log Analysis, Threat Hunting, LOLBin Detection, Process Analysis, Incident Timeline Reconstruction

Conducted a Windows security investigation using Splunk to analyze process creation activity and identify suspicious behavior across multiple endpoints.

During the investigation, I:

* Analyzed Windows Event ID 4688 process-creation events.
* Identified anomalous user activity and an imposter account.
* Investigated scheduled-task activity using schtasks.exe.
* Identified abuse of the Windows LOLBin certutil.exe.
* Analyzed command-line arguments to identify a malicious payload download.
* Traced the download of benign.exe from an external file-sharing service.
* Pivoted across usernames, hosts, processes, URLs, filenames, and timestamps to reconstruct the attack timeline.
* Used Splunk SPL queries to filter and correlate endpoint activity.

Key Skills Demonstrated: Splunk SPL, Windows Event Analysis, Threat Hunting, LOLBin Analysis, Command-Line Analysis, Incident Investigation
